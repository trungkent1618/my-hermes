# Agnes AI + R2 Storage Integration

## When to use
After generating images or videos with Agnes AI, upload to Cloudflare R2 for:
- Permanent public URLs (URLs from Agnes CDN expire after some time)
- Free tier (10GB storage, 10M reads/month, 1M writes/month)
- Fast CDN delivery via Cloudflare
- Zero egress fees

## Current Configuration (2026-08-27)

### Buckets Created
| Bucket | Purpose | Custom Domain | Public Access |
|--------|---------|---------------|---------------|
| `hermes-image-db` | Images | `media.wanderlee.site` | ✅ Enabled |

Configurados en `~/.hermes/.env`:
```bash
R2_ACCOUNT_ID=your_account_id_here
R2_ACCESS_KEY_ID=your_access_key_here
R2_SECRET_ACCESS_KEY=your_secret_key_here
```

## What's Still Needed

### Enable Public Access (REQUIRED for URLs to work)
R2 buckets are private by default. To enable public URLs:

1. Go to: https://dash.cloudflare.com/?to=/:account/r2/overview
2. Select bucket (`hermes-image-db` or `hermes-video-db`)
3. Settings → Public Access
4. Enable:
   - [x] Enable public bucket
   - [x] Enable r2.dev URL (for `pub-xxx.r2.dev` format)
5. Save and repeat for both buckets

### File Naming Pattern
```
images/2026-08-27_123456_hash.png
videos/2026-08-27_123456_hash.mp4
```

## Public URL Format

### With r2.dev Domain Enabled
```
https://pub-<hash>.r2.dev/<key>
```
Where `<hash>` = MD5(account_id)[:8]

Example:
```
https://pub-2884c63d.r2.dev/images/2026-08-27_123456.png
```

**Note:** Requires r2.dev domain to be enabled in Cloudflare dashboard.

## Setup (For New Users)

### 1. Create R2 Buckets
Via Dashboard or CLI:
```bash
wrangler r2 bucket create hermes-image-db
wrangler r2 bucket create hermes-video-db
```

### 2. Create R2 API Token
Dashboard → R2 → API Tokens → Create token
- Template: **"Object Read & Write"**
- Scope to buckets: `hermes-image-db`, `hermes-video-db`
- Client IP filter: your egress IP (e.g., `161.153.193.243`)

### 3. Store credentials
```bash
# In ~/.hermes/.env
R2_ACCOUNT_ID=xxx
R2_ACCESS_KEY_ID=xxx
R2_SECRET_ACCESS_KEY=xxx
```

### 4. Enable Public Access
Dashboard → R2 → Select bucket → Settings → Public Access

## Plugin Integration

Images and videos generated by Agnes plugins are automatically uploaded to R2 if credentials are present. The plugin checks for R2 credentials and uploads if available. Falls back to local storage if R2 not configured.

## Portability (2026-08-27)

### Environment Variable Substitution
Hermes supports `${VAR_NAME}` syntax in config.yaml:
```yaml
custom_providers:
  - name: agnes
    api_key: ${AGNES_API_KEY}
```

### .env.example Template
A portable template exists at `~/.hermes/.env.example` for sharing configuration without exposing secrets.

To share your setup:
1. Copy `config.yaml` (already uses env vars)
2. Copy `plugins/` and `skills/` directories
3. Share `.env.example` as template
4. User creates their own `.env` from the example

### What to Exclude from Sharing
- `~/.hermes/.env` — contains your secrets
- `~/.hermes/mcp-tokens/` — contains OAuth tokens
- `~/.hermes/image_registry.json` — your generated images
- `~/.hermes/cache/` — temporary files

## Portability (2026-08-28)

### Export/Import Profile
```bash
# Create export (includes config, plugins, skills)
hermes profile export default -o agnes-setup.tar.gz

# Share and import elsewhere
scp agnes-setup.tar.gz user@remote:~/
hermes profile import ~/agnes-setup.tar.gz
```

### What's Included in Export
- `config.yaml` with `${AGNES_API_KEY}` placeholder syntax
- `plugins/` directory (image_gen/agnes, video_gen/agnes)
- `skills/mlops/` with setup documentation

### What's NOT Included (Secure by Design)
- `~/.hermes/.env` — your API keys and secrets
- `auth.json` — OAuth tokens
- `state.db` — conversation history
- `image_registry.json` — your generated media

### Post-Import Setup
1. Create `~/.hermes/.env` with your credentials
2. Copy from `.env.example` template
3. Configure R2 buckets in Cloudflare dashboard
4. Run: `hermes profile import ~/agnes-setup.tar.gz`

## R2 Pricing (Free Tier)

| Resource | Free Allowance | Overage |
|----------|---------------|---------|
| Storage | 10 GB/month | $0.015/GB |
| Class A ops (writes) | 1M/month | $4.50/M |
| Class B ops (reads) | 10M/month | $0.36/M |
| Egress | Unlimited | **FREE** |

**Note:** R2 charges per account, NOT per bucket. Multiple buckets = same cost.

## Troubleshooting

### 401 Unauthorized
Token lacks R2 permissions. Verify:
- Token scope: "Object Read & Write"
- Token applied to correct buckets
- IP filter matches your egress IP

### 404 Not Found (public URL)
Public access not enabled. Check dashboard:
- Bucket → Settings → Public Access
- Ensure "Enable public bucket" is ON

### AccessDenied on bucket operations
Token doesn't have admin permissions. Use:
- "Object Read & Write" for object operations only
- "Admin Read & Write" for bucket configuration
